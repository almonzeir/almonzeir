## 2024-05-22 - Interactive Markdown Patterns
**Learning:** Users often perceive "interactivity" as simply "hiding/showing" content. In static environments like GitHub READMEs, `<details>` and `<summary>` tags provide a semantic, accessible way to create "interactive" dropdowns without JavaScript.
**Action:** Use native HTML details/summary for progressive disclosure in static docs to delight users requesting "apps" in Markdown.
