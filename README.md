# Almonzer Hamid

Machine learning engineer working on **Arabic NLP and large language models**, with a focus on low-resource Arabic dialects. Native Sudanese Arabic speaker. B.CS (Data Science), Albukhary International University, Malaysia.

**Current research direction:** measuring and closing the Sudanese Arabic gap in LLMs. Sudanese is missing from DialectalArabicMMLU and NADI 2025, and its only text benchmark so far (Sudanese-Flores, 2026) covers translation only. I'm working on an evaluation set for understanding and generation, and on parameter-efficient adaptation of small open models.
